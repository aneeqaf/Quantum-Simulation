This python script illustrates how to configure simulator parameters for distributed simulation, launch multiple simulator runs, and then to collect results. The script first launches a trial run and looks at runtime. If runtime is <1s or if it cannot find runtime in the simulator output, it quits and complains (in case the run failed for some reason, such as bad input or an internal error). The same happens if the runtime was too large. Otherwise, the script can estimate how many CPU hours will be used by the entire simulation. The script also prevents redundant simulation runs by adjusting the input CZ path length after performing a trial simulation run with vertical and horizontal cut simulation.
